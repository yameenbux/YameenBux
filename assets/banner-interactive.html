Why the README version can't do this

GitHub renders README images in an <img>, and pointer events never reach an image — whatever the format. The shipped banner is an animated PNG: it plays the entrance once and rests, so it keeps the motion from this page and drops only the cursor response, the one thing that needs a live document.

Inside a README the achievable maximum is an animated banner wrapped in a link, which is what assets/banner-dark.png and assets/banner-light.png do. This file is standalone: drop it on any page you control — a GitHub Pages site, for instance — and the full interaction layer works.
