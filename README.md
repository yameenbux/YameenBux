**Senior IT Infrastructure Engineer** moving into **Cloud & DevOps** — and proving it by shipping real, cloud-backed products, not just studying for them.

## 🚀 Featured build — Taiyabah Masjid digital ecosystem

One project, four connected products for a Bolton community — designed, built and deployed end to end:

- 📱 **Progressive Web App** — prayer times, live audio streaming, Qibla compass, zakat calculator, push notifications
- 🖥️ **Public website** — full rebrand + new-build fundraising appeal
- 📺 **In-building digital signage** — fullscreen kiosk displays (landscape *and* portrait) with live countdowns and scheduled auto-refresh

**Under the hood:** Cloudflare Workers (serverless edge backend) · OneSignal push · **CI/CD with GitHub Actions** · Python data pipeline · installable, offline-ready PWA · Hijri date + Qibla geolocation
